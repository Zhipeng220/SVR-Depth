# R3.3 实验协议：候选几何差异分解与写回收益诊断

## 研究问题

R3.2 中单一相对深度残差的阈值规则没有超过 AgeGate。R3.3 不继续调阈值，而是诊断候选深度与传播深度之间的差异由什么组成，并检验这些几何描述与同状态写回未来收益之间是否存在可重复的描述性关系。

## 冻结协议

- 序列：Crowd2、Balloon2、Crowd3。
- 帧数：86。
- 实际在线动作锚点：零基帧 9、37、65。
- 实际在线策略：只在这三个锚点执行 AgeGate（`distance_kf >= 16`）；其他诊断锚点不写回。
- 诊断锚点：零基帧 1 起，每 4 帧一个锚点，且必须满足 `anchor + H < T`。H=16 时为 1、5、9、...、69。
- 每个诊断锚点额外生成候选，仅用于特征记录；如果不是实际动作锚点，则丢弃候选且当前帧继续使用传播输出。
- 权重冻结，不训练预测器。
- GT 不参与特征提取、门控或动作选择；未来 GT 仅用于同状态 B0/B1 反事实结果评价。

## 几何差异分解

对共同有效的正深度像素，拟合 `D_candidate ~= a * D_propagation + b`，使用确定性抽样与 Huber IRLS。记录：

1. 原始相对差异的均值、中位数和 P90；
2. 全局尺度 `a`、偏移 `b`、归一化偏移与 `|a-1|`；
3. 去除全局 scale-shift 后的归一化残差均值、中位数、P90、高残差比例；
4. 4×4 网格中的残差变异与最大局部残差。

这些指标仅是当前候选和传播结果的描述性几何特征，不预设它们一定表示“有害写回”。

## 写回收益标签

每个有效锚点从同一帧传播后状态分叉：

- B0：不写回候选几何字段；
- B1：将候选的四个审计几何字段写回。

两分支未来独立递推并分别执行自身原生重启；不执行未来可选动作。标签为：

`gain = sum_k gamma**k * (AbsRel_B0[k] - AbsRel_B1[k]) / valid_paired_frame_count`

gamma=0.9，H=16。正值表示该局部反事实下写回降低未来 AbsRel。该标签不是完整在线策略收益，也不等于当前帧输出收益。

## 输出

- `r33_geometry_gain_diagnostics.csv`：每个锚点的特征、收益标签和跳过原因。
- `r33_future_branch_trace.csv`：未来各步 B0/B1 的指标与原生重启。
- `r33_feature_gain_association.csv`：全体与逐序列的 Pearson/Spearman 描述性关联、特征四分位收益差。
- `r33_online_frame_metrics.csv`：AgeGate 实际动作锚点轨迹的帧指标和动作记录。
- `r0_runtime_audit.json`、`source_audit.json`、`metadata.json`。

## 解释限制与决策规则

- H=16 的相邻未来窗口重叠，锚点不独立；相关系数不报告 p 值，也不用于在同一批序列上选阈值。
- 3 条序列均是开发序列，不能当独立测试。
- 诊断额外计算候选与反事实分支，不能把时间作为部署延迟，也不能声称节省候选推理。
- 若几何特征只在合并数据中相关、逐序列方向不稳定，视为未得到跨序列机制证据。
- 只有在特征方向和效应在多个序列上可复现后，才考虑预先指定的单一规则；否则停止特征堆叠，转为机制分析结果。
